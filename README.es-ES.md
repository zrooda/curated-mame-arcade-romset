# ROMset Curado de Arcade MAME

👉 [¡Haz clic aquí para la lista sin procesar!](ROMSET)

Un conjunto seleccionado a mano de lo mejor | más extraño | más memorable | técnico | significativo que ofrece la historia de los juegos de Arcade (para MAME/FBNeo).

- Incluye Neo Geo
- Espera un conjunto MAME no fusionado ([¿Qué?](https://wiki.romvault.com/doku.php?id=merge_types))
- Se prefieren versiones compatibles con [RetroAchievements.org](https://retroachievements.org/)

_¡Haz un PR si te falta tu juego favorito!_

## Hoja de ruta
- Scripts de Bash/PowerShell que copian los archivos .zip y CHDs relevantes de un conjunto completo
- gamelist.xml y medios para EmulationStation y otros frontales
